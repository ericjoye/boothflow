# BoothFlow Store Listing

App name: BoothFlow
Short description: Photo booth quote, booking, and gallery PWA for rental operators.
Long description: BoothFlow is a lightweight PWA built for small photo booth rental businesses. Operators can build branded quotes fast, keep bookings and galleries in one place, run event-day checklists, and trigger rebooking reminders. The app works offline and stores data locally. Free tier is usable immediately; paid tiers unlock instant quotes, branded galleries, follow-ups, and multi-operator workflows.
